# 📡 Monitor de Serviço e Rede Linux

Um script simples e eficiente em Shell Script (Bash) para monitorização de conectividade de rede e testes de resolução de DNS em ambientes Linux.

---

## 📂 Estrutura do Repositório

| Ficheiro | Descrição |
| :--- | :--- |
| [`monitor.sh`](monitor.sh) | Script principal de automação que executa os testes de rede. |
| [`status_servicos.log`](status_servicos.log) | Ficheiro de log gerado automaticamente após a execução. |
